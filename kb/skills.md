## How to read this file

- Version order is TENTATIVE. All 28 versions are dated 2026-04 to 2026-09 by content lower bounds, and many share a month. The order used for first_seen / last_seen is the order of the V01-V28 legend below (by date, then lineage and version number). Treat first_seen / last_seen as "earliest / latest in this tentative order", not as proof of when a skill was added.
- Skill names are used as written in the source lists (original capitalization of the first occurrence). Matching across versions is case-insensitive and otherwise exact, so the same idea worded differently is a separate line ("Multi-workstream project coordination (6+ concurrent)" and "multi-workstream management (6+ concurrent)" are separate lines). Nothing was merged, inferred, or added.
- Items are split on commas (or on semicolons where a list uses semicolons), outside parentheses. A long comma-separated phrase in a source list may therefore appear as several short lines (for example "work group" and "focus group" from "work group, focus group, and committee facilitation").
- roles: employer slugs where the skill's literal wording (case-insensitive, punctuation ignored, parenthetical qualifiers also tried alone, trailing "EHR/CRM/LMS" also dropped) appears in a role bullet. A bullet's employer was decided by the closest matching bullet in the versions whose employer headings are intact, not by the heading it sits under, because several files put every job's bullets under NCMW. `unplaced` means the literal wording is in a bullet whose employer could not be decided that way.
- listed-only: no bullet contains the literal wording. Because matching is literal, long descriptive phrases that a bullet paraphrases are still marked listed-only; read it as "not literally evidenced in a bullet", not "unsupported".
- sources: version codes from the legend. `all-versions` means all 28 versions V01-V28 (V29-V32 are listed explicitly when a skill appears in them; for Zoom, V29-V32 also list it) (the duplicate raw file is not counted as a separate version).
- Categories below are this file's grouping. A skill sits under the category of the list it first appeared in; the source lists use many different category names.
